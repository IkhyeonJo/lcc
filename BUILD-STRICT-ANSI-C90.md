# LCC 3.6 — Strict ANSI C90 build

This distribution is LCC 3.6 modified to reject the user-program extensions identified in the source audit.

## Rejected

- C++ `//` comments
- `#error`
- LCC-specific `#eval`
- `#pragma` (intentionally stricter than ordinary C90 implementation-defined pragma handling)
- trailing comma in enumerator lists
- trailing comma in initializers
- LCC driver predefined `__LCC__` and `unix` macros

## Build

The checked-in `lburg/gram.c` is copied to `build/gram.c`, so a yacc/bison executable is not required for this source distribution.

The compiler components were successfully built with a modern GCC in GNU89 compatibility mode:

- `build/lburg`
- `build/cpp`
- `build/rcc`
- `build/lcc`
- `build/bprint`
- `build/bbexit.o`

The `rcc` target backends generated by lburg were also built.

## Important

The historical LCC distribution is a C90-era compiler and its native host/target drivers are platform-specific. This package's strictness concerns the language accepted from user C programs; it does not claim ISO C90 formal-conformance certification for every implementation-defined behavior or translation limit.
